# Architecture

Architecture decision records (ADRs) for Project Helix.

No source code lives here — this repository is governance and standards only.

## Recording a decision

Write an ADR when a decision is expensive to reverse, affects more than one team or service,
or will make a future reader ask "why on earth is it like this?"

1. Copy [../templates/adr.md](../templates/adr.md) to
   `architecture/decisions/NNNN-short-slug.md`, numbered sequentially.
2. Open it as a PR ([CONTRIBUTING.md](../CONTRIBUTING.md)).
3. Status `proposed` while under discussion, `accepted` on merge.

Never edit an accepted ADR to change the decision. Write a new one and mark the old one
`superseded by ADR-NNNN`.
